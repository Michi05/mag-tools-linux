# browser_youtubewl_cleaner

A local, self-contained HTML utility for managing a YouTube Watch Later
playlist. No server, no dependencies — pure client-side HTML/JS, so it's
identical on Linux and Windows. Copied unchanged from the Windows repo.

## Usage

Open directly in a browser:

```
xdg-open "TOOLS/browser_youtubewl_cleaner/YoutubeWL Cleaner 230504.html"
# or: brave-browser "TOOLS/browser_youtubewl_cleaner/YoutubeWL Cleaner 230504.html"
```
