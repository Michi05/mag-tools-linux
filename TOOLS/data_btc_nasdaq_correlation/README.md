# data_btc_nasdaq_correlation

Interactive HTML visualization (`bitcoin_vs_nasdaq.html`) and its backing
data (`ndx_weekly.json`). Self-contained artifact — open the HTML to view the
chart. No server, no dependencies, identical on any OS.

Renamed from `BTC-Nasdaq correlation` (spaces in a directory name are fragile
for shell scripting) to the `data_` category prefix, consistent with the rest
of this repo's naming convention.

## Usage

```
xdg-open bitcoin_vs_nasdaq.html
```
